The animated logo

A scanning lens: the outer ring sweeps, the inner ring counter-rotates, and three markers blink on in sequence as the scan turns things up. Every file is self-contained — the animation lives inside the SVG, so it plays in an <img>, a slide deck, or a README with nothing else attached.

AI Code Archaeologist
Drop in a codebase. Get an X-ray of how it works.

Variants

logo.svg — dark
logo-light.svg
mark.svg — small sizes

How it holds up small

Which file to use

FileUse it for
logo.svgAnything 48px and up on a dark background — slides, the title screen, the README header.
logo-light.svgThe same, on a white or light background. The cyan is deepened so it does not wash out.
mark.svgFavicons, avatars, the navbar — anything under 48px, where the sweep and markers turn to mush.

Dropping it in

<!-- animates on its own, no CSS needed -->
<img src="brand/logo.svg" width="120" height="120" alt="AI Code Archaeologist">

<!-- as the browser tab icon -->
<link rel="icon" href="brand/mark.svg">

<!-- in a README on GitHub -->
<p align="center"><img src="brand/logo.svg" width="140"></p>
Motion stops automatically for anyone who has prefers-reduced-motion switched on — the mark still reads, it just holds still.
